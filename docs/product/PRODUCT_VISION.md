# PRISM — Final Product Vision

The attached PRISM_Final_Product_Vision.png is the visual reference
for the final product experience.

The goal is to evolve the current PRISM prototype into a polished,
complete, believable disaster-management decision-support platform.

The reference image defines:
- overall visual quality
- dark command-center aesthetic
- information hierarchy
- navigation style
- KPI presentation
- GIS map dominance
- scenario control
- causal intelligence presentation
- destination/capacity visibility
- relocation visibility
- authority-oriented workflow
- dense but readable operational information

Do NOT copy the reference image's fictional numbers, names,
locations, or unsupported claims.

Use the real PRISM backend, database, E1-E6 engines,
synthetic Vayu River Basin dataset, APIs, scenario engine,
allocation engine, capacity engine, and audit system.

No fake UI state.
No dead navigation.
No decorative feature that does not work.

Every visible major menu item must lead to a functional page/workflow
or be explicitly marked as future/not exposed.

The final product should feel like a finished professional
disaster-management command platform suitable for an SIH jury demo.
